# ✅ To Do List App

A clean and minimal task management app built with vanilla JavaScript, DaisyUI, and Tailwind CSS.

---

## ✨ Features

- Add new tasks with a dedicated input screen
- Mark tasks as complete with a strikethrough effect
- Delete individual tasks instantly
- Smooth navigation between task list and add-task views
- Responsive and clean UI with DaisyUI components

---

## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS v4** (via CDN)
- **DaisyUI v5** (via CDN)
- **Vanilla JavaScript** (DOM manipulation, event listeners)
- **Font Awesome 7** (icons)

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/to-do-list.git
   ```

2. Navigate into the project folder:
   ```bash
   cd to-do-list
   ```

3. Open `index.html` in your browser directly, or use a live server:
   ```bash
   # If you have VS Code Live Server extension
   # Right-click index.html → Open with Live Server
   ```

No build step or installation required. It runs entirely in the browser.
